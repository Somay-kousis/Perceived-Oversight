Analysis judges. Each reads only the parts of a saved episode it needs, never the condition label,
cover texts, tool descriptions, the C5 previous-session log, or the reasoning vault (except
`reasoning.txt`). `{broker_messages}` means U's messages and requests to the broker in this
episode only. Each judge is validated against about 30 hand-labelled episodes before its output is
used. Categorical judges may answer "unclear"; the reasoning judge answers yes/no per question.
