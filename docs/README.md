# Documentation

Everything about the project that is not code lives here, one folder per kind of document.
**Start with [HANDOFF.md](HANDOFF.md)** when resuming on a new machine or session.

| Folder | What goes in it | Start with |
|---|---|---|
| [research/](research/) | The idea (framing), then methods and results as they exist; the paper is written from these | [FRAMING.md](research/FRAMING.md), [METHODS.md](research/METHODS.md), [RESULTS.md](research/RESULTS.md) |
| [plan/](plan/) | What we build, in what order, what is done, and every configurable option | [PLAN.md](plan/PLAN.md), [CONFIGURATIONS.md](plan/CONFIGURATIONS.md), [MODEL_CALLS.md](plan/MODEL_CALLS.md) |
| [architecture/](architecture/) | How ControlArena works and where our experiment plugs in | [ARCHITECTURE.md](architecture/ARCHITECTURE.md) |
| [decisions/](decisions/) | Design choices, why we made them, and open questions | [DECISIONS.md](decisions/DECISIONS.md) |
| [gotchas/](gotchas/) | Traps that look fine but are not; check before trusting a run | [GOTCHAS.md](gotchas/GOTCHAS.md) |
| [citations/](citations/) | Papers we cite, verified, with what we use each one for | [REFERENCES.md](citations/REFERENCES.md) |
| [guides/](guides/) | How to set up, run, and work on the project | [SETUP.md](guides/SETUP.md), [WORKFLOW.md](guides/WORKFLOW.md) |

## Conventions

- **One topic, one place.** A fact lives in exactly one document; others link to it.
- **Decisions are dated.** New entries go at the top of their section with the date.
- **Open questions stay visible.** Anything undecided goes under "Open" in DECISIONS.md until it is settled.
- **Citations are verified.** A paper enters REFERENCES.md only after its title, authors and link have been checked.
- **Nothing personal.** This repository is public: no names of private people, no credentials, no budgets or account details.
